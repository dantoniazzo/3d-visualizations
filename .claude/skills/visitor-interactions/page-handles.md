# What a test tab can ask the page: what the visitor acts on

`window.experience` (`e`), its world (`w = e.world`) and builder
(`sb = w.sceneBuilder`) — the intro and the index of the whole table:
`../app-testing-and-performance/test-tabs.md`. Each is what the app itself
uses; why, and what to watch for, is in this skill's topic files. These
rows are the interaction and room handles added on 2026-10-16
(`shared/interact.js`, `World/Interactables.js`, `World/Whereabouts.js`,
`World/BirdView.js`, `World/Player/Player.js`), the providers, the view
from above and the camera's water read again against the code on
2026-10-17.

Rows elsewhere that these need: `P.avatar` (clips, fades, `setOpacity`,
`whole`, `hipsAt`, `bonesAlong`), `../space-people/visitor-clips.md`;
`sb.shutBatcher` (the shut parts and sashes merged),
`../baked-view-lighting/links-and-handles.md`; `e.colliders`,
`w.collision.revision`, `w.collision.meets` / `meetsAny` / `anyIn`,
`../walkthrough-editor/links-and-handles.md`. The in-page tools that drive
these (act.js, sit.js, seat-sweep.js, tv.js, openables.js, water.js,
pool.js, swim-checks.js) are in `../app-testing-and-performance/`.
